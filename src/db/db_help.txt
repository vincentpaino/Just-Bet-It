Shared team database (Neon): connect with the connection string from your
.env (DATABASE_URL), in quotes:

psql "postgresql://user:password@ep-xxxx.neon.tech/neondb?sslmode=require"

Tip: `export DATABASE_URL=...` in your terminal, then use psql "$DATABASE_URL".

Local database:

To connect and view the PostreSQL data, use this CLI command:

psql -h localhost -p 5432 -U <user-name> -d just_bet_it

Or, you could stay in the virtual environment and access data like this (print results and exists):

psql -d just_bet_it -c "<command>"

psql -d just_bet_it -c "SELECT COUNT(*) FROM games; SELECT * FROM games LIMIT 10;"

psql -d just_bet_it -c "SELECT * FROM users WHERE username = 'alice';"

From here, you can use various commands like this:

just_bet_it=# <insert-command-here>

List of useful commands:

    dt                              -- confirm the six tables exist
    \d <table-name>                 -- column/feature names and types
    SELECT COUNT(*) FROM games;
    SELECT * FROM games LIMIT 10;
    \x auto                          -- switches to vertical output when rows are wide
